# Switch every GPT classifier to gpt-6-luna

Date: 2026-11-04
Branch: worktree-gpt-6-luna
Status: approved by Yoav ("switch all + retune", then "ship luna's stricter RSoC"), building.

## Goal and constraints

Yoav asked to move the GPT model to gpt-6-luna. Every chat call in the repo used gpt-4.1-mini:
the scraper's 7 detectors (language, country, vertical, brand, creative language, prohibited
content, RSoC risk), the backfills sharing their prompts, the article-family classifier, and the
web AI Draft route. Labels drive filters and hide ads (prohibited content), so the switch must
not silently change what people see.

## Verified facts (2026-11-04)

- Official model page: reasoning model, default effort medium; Chat Completions supported; image
  input; $0.10 in / $0.50 out per 1M tokens (gpt-4.1-mini: $0.40 / $1.60).
- Live calls: `max_tokens` -> 400; `temperature: 0` -> 400 unless `reasoning_effort: 'none'`;
  default reasoning with a 10-token cap -> HTTP 200, empty text (all tokens spent reasoning).
- Even with reasoning off it spends ~3 tokens beyond the answer: `car_brand` costs 5, not 2. With
  the old 3-token cap, a plain swap returned blank brand on 60 of 60 ads.
- All three fail silently: the detectors turn a blank into "not classified".
- Volume: ~11,300 new ads/month x 7 calls. Savings roughly $20-25/month (estimate, not metered).

## Approach (chosen)

- New `gpt.py`: `CHAT_MODEL` + `chat_params(answer_tokens)` (`max_completion_tokens` with 16 tokens
  of headroom, `reasoning_effort: 'none'`, `temperature: 0`). Every Python call site uses it; the
  per-module model constants are gone. A future model change is one edit.
- Web AI Draft: same model, `reasoning_effort: 'none'`, `max_completion_tokens`.
- Prompt retuning, measured against the labels production stored:
  - brand: "the website the ad links to or is published on is the publisher, not a brand"
    (luna counted knowrift.com etc. as brands: 49% of ads before, 92% match after).
  - prohibited: adult and political defined narrowly (government programs are not political;
    beauty/massage/wellness alone is not adult).
  - RSoC: yellow/green spelled out (loans, credit, insurance, investing, health advice = yellow;
    education, jobs, travel, housing info, shopping guides = green unless they promise money,
    approval or a result).

## Results on 150 real ads (stored labels; "floor" = gpt-4.1-mini re-run on the same prompts)

| Detector | floor | luna | Verdict |
|---|---|---|---|
| language | - | 100% | same |
| country | 97% | 90% | luna MORE accurate vs measured revenue country: 94% vs 90% on 200 campaigns |
| brand | 97% | 92% | differences go both ways; several stored labels were wrong |
| creative language | 99% | 95% | fine |
| prohibited | 97% | 95% | 3 of luna's 4 new "adult" flags are genuinely suggestive images (viewed); 1 wrong |
| RSoC | 87% | 68% | luna applies the written yellow rule; approved by Yoav as stricter |
| vertical | 89% | 76% | noisy field for both models (keyword shortlist; see follow-up) |

## Rejected

- Plain model swap: blanks every brand label and anything with a tight cap.
- Reasoning `low`: brand got worse (52 more "brand"), more cost and latency.
- Keeping some detectors on gpt-4.1-mini: two models to maintain; not needed after retuning.

## Follow-up (not in this PR)

- Vertical shortlist: `_shortlist_verticals` keeps only keyword overlaps, so some ads get a list
  of 1-3 unrelated verticals (seen: an auto-mechanic course offered only "Bad Breath Remedy").
  luna obeys "choose from the list"; gpt-4.1-mini often answered off-list. Embedding shortlist
  like article_verticals.py is the fix.

## Security

No new secret or dependency. Same OpenAI key, same endpoints. No data written by this change
beyond the labels the scraper already writes.

## Testing / deploy

- `tests/test_gpt.py`: settings pinned, no Python call site may send `max_tokens`, all 7 scraper
  detectors send the shared model + settings. Python 226 + web 293 green, `next build` clean.
- Live end-to-end with the shipped code: 1,050 calls, all 200, no unexpected blanks.
- Deploy: merge -> Vercel (AI Draft); the scraper uses it on its next run. Rollback: revert, or set
  `gpt.CHAT_MODEL` back (and the draft route) - but `chat_params` must then drop
  `reasoning_effort`, which gpt-4.1-mini rejects.
